What Is TIFF and Where Does It Still Rule?

TIFF (Tagged Image File Format) is the heavyweight of image formats — lossless, high-bit-depth, and capable of holding multiple pages in a single file. It was built for print shops, scanners, and archives, and in those worlds it never left. Legal document systems, medical imaging workflows, government archives, and print prepress pipelines still treat TIFF as the default.

Its killer feature for document work is the multi-page TIFF: one file containing every page, like a PDF but as pure images. Fax systems, older scanners, and many enterprise content-management platforms ingest multi-page TIFFs natively. If someone asks you for a TIFF, they usually mean one file with all the pages inside, at 300 DPI, ready for their system.

The trade-off, as always with lossless formats, is size. TIFFs are big — a 300 DPI page can run several megabytes, and a 50-page document becomes a hefty file. But in the worlds that demand TIFF, storage was budgeted for exactly this long ago.

Hit Convert and download. My check: open the TIFF and zoom to 100% — text should be crisp with no compression artifacts (TIFF is lossless, so any softness means the DPI was too low, not the format). For multi-page TIFFs, confirm the page count and order match the PDF.

A practical note on color: most document TIFFs are black-and-white (1-bit) or grayscale, which keeps files dramatically smaller than full color. If your pages are text documents, grayscale at 300 DPI is the sweet spot — color adds megabytes for no benefit on a contract.

Frequently Asked Questions

Why does the recipient want TIFF instead of PDF?

Their system — legal, medical, archival, or print — was built around TIFF decades ago. Multi-page TIFFs feed directly into those workflows without conversion.

What DPI should I use?

300 DPI is the standard for archival and legal document imaging. Use 200 DPI if file size is a concern and the recipient allows it.

Should I use color or grayscale?

Grayscale for text documents — dramatically smaller files with identical readability. Reserve color for pages where color carries information (stamps, highlighted figures).

What is a multi-page TIFF?

A single TIFF file containing all pages, like a PDF but as pure images. Most document systems that ask for TIFF expect this format.

Why are TIFF files so large?

Lossless quality at high resolution takes bytes. LZW compression trims the size safely without losing anything.
